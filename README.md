
\# IT Support Home Lab



\## Overview

This project simulates real-world IT support scenarios using a virtual machine environment. It demonstrates troubleshooting skills commonly required in entry-level IT help desk roles.



\## Objectives

\- Simulate common IT support issues

\- Practice diagnosing and resolving technical problems

\- Document troubleshooting steps clearly and professionally



\## Tools Used

\- VirtualBox

\- Windows 10 Pro



\## Project Structure

\- screenshots/ → Contains visual proof of issues and fixes

\- documentation/ → Contains written explanations for each scenario



\## Scenarios

1\. No Internet Connectivity

2\. Account Lockout

3\. Slow PC Performance

4\. Application Not Working

5\. File Permission Issues



\## Status

In Progress
